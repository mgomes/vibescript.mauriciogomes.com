 Language

    
Small surface. Sharp primitives.

    
Everything in Vibescript is designed to be read at a glance — by your team, and by the models writing it.

  


  

    

      
Reads like Ruby. Types when it matters.

      

        Blocks, ranges, zero-paren defs, symbol hashes — syntax your team and every
        language model already know. Annotations are optional, but signatures are checked
        when you write them, and nullables are always explicit.
      

    

    

      

        

          typing.vibe
        

        
def shipping_quote(speed, subtotal: money) -> hash
  fee = shipping_fee(speed, subtotal)
  transit = transit_time(speed)

  {
    speed: speed.name,
    fee: fee,
    total: subtotal + fee,
    transit: transit.iso8601
  }
end

      

    

  


  

    

      
Drops into your Go app in an afternoon.

      

        One go get, three calls: build an engine, compile the script, call a
        function. Scripts expose functions to the host; the host exposes exactly the
        capabilities it chooses back.
      

    

    

      

        

          main.go
          host side
        

        
engine, _ := vibes.NewEngine(vibes.Config{
  StepQuota: 250_000,
})

script, _ := engine.Compile(userScript)

fee, _ := script.Call(ctx, "late_fee", args, opts)
fee.String() // "5.00 USD"

      

    

  


  

    

      
The sandbox says no.

      

        A runaway loop, a hostile script, an AI hallucination with a while-true in it —
        the engine stops it at the step quota and hands your Go app a clean error.
        No goroutine leak, no OOM, no incident channel.
      

    

    

      

        

          untrusted.vibe — sandboxed
        

        
$ cat untrusted.vibe
def run
  balance = 0
  while true

  end
end

Money is money. Time is time.

      

        3.days is a duration, not an integer with a comment. Money never
        loses a cent to float rounding. Enums are first-class values, not strings you
        promise to spell consistently.
      

    

    

      

        

          primitives.vibe
        

        
enum ShippingSpeed
  Economy
  Priority
  Overnight
end

def transit_time(speed: ShippingSpeed) -> duration
  if speed == ShippingSpeed::Overnight
    6.hours
  else
    5.days
  end
end

def net_after_fee(cents)
  gross = money_cents(cents, "USD")
  gross - money("1.75 USD")
end

      

    

  






  
  

    
 Designed for AI

    
Easy to read. Easy for AI to vibe code.

    

      As vibe coding spreads, most products need limits on what users can build. Instead of a blank canvas,
      Vibescript hands them an opinionated set of primitives that combine into predictable, safe applications.
    

    

      Think of it less like traditional software development and more like HyperCard: flexible, but within bounds.
      The Ruby-like syntax mirrors patterns familiar to language models, making it a natural target for AI-generated code.
    

    

      Vibescript embeds directly into any Go application. Scripts expose functions callable from host code,
      and the host controls exactly what capabilities each script can access.
    

  


  

    
Sandbox guardrails

    
Defaults favor safety over throughput. Adjust per use case.

    

      

        
 Step quota {{.Guardrails.StepQuota}}

        
Caps execution steps to prevent unbounded loops.

      

      

        
 Recursion limit {{.Guardrails.RecursionLimit}}

        
Bounds call depth to prevent stack blowups.

      

      

        
 Memory quota {{.Guardrails.MemoryQuota}}

        
Limits allocations so scripts fail cleanly instead of OOMing the host.

      

      

        
 Effects control strict

        
Side-effecting operations require explicit capabilities.

      

      

        
 Module paths allowlist

        
Module lookups only resolve inside directories you approve.

      

      

        
 Capability gating host adapters

        
Scripts only touch the safe adapters you expose.
