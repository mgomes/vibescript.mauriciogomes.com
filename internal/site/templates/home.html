 Language

    
A familiar language for app logic.

    
Use Ruby-like syntax, optional types, and built-in money, duration, and enum values.

  


  

    

      
Ruby-like syntax with optional types.

      

        Blocks, ranges, calls without parentheses, and symbol-keyed hashes will look
        familiar to Ruby users. Types are optional. When you use them, Vibescript checks
        arguments and return values. Nullable types stay explicit.
      

    

    

      

        

          typing.vibe
        

        
def shipping_quote(speed, subtotal: money) -> hash
  fee = shipping_fee(speed, subtotal)
  transit = transit_time(speed)

  {
    speed: speed.name,
    fee: fee,
    total: subtotal + fee,
    transit: transit.iso8601
  }
end

      

    

  


  

    

      
Embed it with three calls.

      

        Create an engine, compile a script, and call a function. Pass app data in and get
        a result back.
      

    

    

      

        

          main.go
          host side
        

        
engine, _ := vibes.NewEngine(vibes.Config{
  StepQuota: 250_000,
})

script, _ := engine.Compile(userScript)

fee, _ := script.Call(ctx, "late_fee", args, opts)
fee.String() // "5.00 USD"

      

    

  


  

    

      
Set hard limits for each script.

      

        Set limits for steps, memory, and recursion. If a script crosses one, the engine
        stops it and returns an error to your Go app.
      

    

    

      

        

          untrusted.vibe · sandboxed
        

        
$ cat untrusted.vibe
def run
  balance = 0
  while true
    balance = balance + 1
  end
end

$ # host calls script.Call(ctx, "run", ...)

✓ stopped at {{.Guardrails.StepQuota}}, Go app keeps running

      

    

  


  

    

      
Built-in money, duration, and enum types.

      

        3.days is a duration, not an integer with a comment. Money uses exact
        decimal values, so float rounding cannot lose a cent. Enums give states a fixed
        set of names.
      

    

    

      

        

          primitives.vibe
        

        
enum ShippingSpeed
  Economy
  Priority
  Overnight
end

def transit_time(speed: ShippingSpeed) -> duration
  if speed == ShippingSpeed::Overnight
    6.hours
  else
    5.days
  end
end

def net_after_fee(cents)
  gross = money_cents(cents, "USD")
  gross - money("1.75 USD")
end

      

    

  






  
  

    
 Extension model

    
Your Go app stays in charge.

    

      Lua is often embedded in games and tools so people can extend them with scripts.
      Vibescript brings that model to Go apps.
    

    

      Each Vibescript extension works through the functions, data, and services your app
      exposes. The rest of the host stays out of reach.
    

  


  

    
Sandbox limits

    
Safe defaults. Change them to fit your app.

    

      

        
 Step quota {{.Guardrails.StepQuota}}

        
Stops scripts after too many execution steps.

      

      

        
 Recursion limit {{.Guardrails.RecursionLimit}}

        
Stops calls that nest too deeply.

      

      

        
 Memory quota {{.Guardrails.MemoryQuota}}

        
Stops scripts after they use too much memory.

      

      

        
 Effects control strict

        
Scripts need permission for operations with side effects.

      

      

        
 Module paths allowlist

        
Scripts can load modules only from approved directories.

      

      

        
 Capability gating host adapters

        
Scripts can use only the APIs you provide.
